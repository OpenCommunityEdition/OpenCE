        Settings

        Written to config.toml and applied now where they can be. A setting its environment variable sets cannot be changed here.

        Ports to open

        Only the tunnel's port needs to reach the internet. Keep the web port on loopback, or behind a proxy that adds TLS (Caddy: reverse_proxy 127.0.0.1:8080), or reach it with ssh -L 8080:127.0.0.1:8080.

        Where files are

        config.toml
        Every setting: beside the executable, or --config
        init.txt
        Commands run at the start (server.init_file), in the data root
        gametypes/
        The operator's gametypes (.toml) and saved ones (.gametype), in the data root
        bans.txt, debug.txt
        In paths.logs, else the data root
        masters.txt
        The master servers, beside the executable
        publisher.key
        The publisher key for the master servers, beside config.toml
        status.json
        The status every 2 seconds (server.status_file)
