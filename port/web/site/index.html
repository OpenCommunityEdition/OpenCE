Halo CE Web

The Halo: Combat Evolved decompilation, running in your browser.

Install it: tap ⬆︎ Share, then Add to Home Screen. The installed app runs full screen and keeps its data.
Install it to play full screen and keep the game data: open the browser's menu ⋮, then Install app (or Add to Home screen).
iPhone tips: swipe down from the top-right to open Control Center. Turn off Portrait Orientation Lock to play sideways. For sound, turn off Silent Mode and raise the volume.

With a Home button, swipe up from the bottom instead. If Silent Mode isn't in Control Center, use your Ring/Silent switch or Action button.
