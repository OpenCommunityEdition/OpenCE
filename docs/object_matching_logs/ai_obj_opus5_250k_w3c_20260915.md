### Laws recorded (candidate additions to the lane law file)

- **L1 SCOPED-LOCAL RECOMPUTE (refines w2 lab law L-A / A29 scoping).** w2's L-A — "one use after a CALL makes a named
  `real` memory-only" — is scope-local. Scoping the local to the block that consumes it and recomputing its defining
  expression at the post-call site keeps January's `fsubr`-in-place + `fst [home]` hold with the home still written
  once and read after the calls. The device is in-file style, not invented steering: this very function already
  computes `segment_vector` twice in two separate scope blocks (January's bytes prove both computations).
- **L2 PARAMETER-HOME ORDER FOLLOWS THE x87 DECISION (refines A24).** The `collision_flags` / time-value parameter-home
  swap is a *consequence* of L1, not an independent tie: declaration order (b3) and parameter-copy order (b2) do not
  move it, while L1 fixes both homes at once. A24's "the local takes over the home" is necessary but does not choose
  which home; definition position does.
- **L3 PAREN BLOCKS FP REASSOCIATION (refines the PAREN/FPU law).** With the value held, VC7 reassociates
  `a*b + c + d*e*f` so the last product is evaluated first; parenthesising the first addend restores January's
  left-to-right order. Removing the inner `(t*t)` parens instead makes VC7 factor the whole expression (wave D bal1,
  928 bytes). Operand order inside the commutative product is canonicalised and inert (A44 confirmed).
