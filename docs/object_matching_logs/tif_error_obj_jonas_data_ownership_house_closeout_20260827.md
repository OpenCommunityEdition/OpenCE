## Exact ownership repair

under static symbol `_rcsid`, followed by static handler slot `_errorHandler` at
offset 92. January owns the same 96-byte section through external symbol
`_data_002b8758`; its handler references are relocations to that owner plus 92.

Renaming the offset-zero array to external `data_002b8758` preserves the exact
96-byte contents and causes the compiler/COFF writer to express all three handler
references through the target owner naturally. No address or offset is written in
C.
