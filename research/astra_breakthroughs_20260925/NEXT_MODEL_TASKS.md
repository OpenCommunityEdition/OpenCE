# Focused continuation tasks

These are research assignments, not pre-approved landings or promises of byte
gain. Start by reading this directory's README, the repository's current house
rules and the target's latest owner ruling. Rebase measurements on the current
canonical commit. Preserve useful nonexact candidates and negative results.
Do not repeat historical sweeps unless an input or causal hypothesis changed.

## Common method

For each hypothesis, state the exact target instruction/slot/call property it
predicts. Use a current untouched compile, factor A, factor B and A+B where
mechanisms can interact. Include an exact sibling and a counterexample. A/B
need not improve bytes individually; joint closure can be meaningful. A finite
search failure means "these forms failed", not "humans could not write it".

Compiler instrumentation must leave generated object contents unchanged.
Changing allocation choices in the compiler can diagnose a constraint but can
never produce credited reconstruction. Do not confuse instruction count,
padded size or pair links with a strict row or whole-object admission.

Production remains untouched until the candidate satisfies house rules and
passes a fresh strict full-board diff, build, parks, source scan, owner/admission
audit, affected provider links in both orders, tests and faithful accounting.
Research can temporarily test a coupled packet with intermediate regressions
in scratch; the final admitted packet must lose no existing exact match.
Existing holds are not lifted by this brief.

## 2. Vehicles scout: scalar forwarding versus representation materialization

Read `scout/measurements.json`, the assembly slot witness and Ghidra export.

the materialize-and-MOV path in a bounded VC7 laboratory. Vary the genuinely

parentheses, volatile or invented conditional may serve as an ordinal knob.

## Stop/reopen and handoff rules

Stop a hypothesis when its unique prediction is falsified, not merely because
the whole function remains residual. Keep the best candidate, exact command,
current source/header/target hashes, all four cell results, inherited exact
controls, and policy status. Distinguish confirmed mechanism, plausible source
reconstruction and approved source. No report may say "unreachable" solely
because a finite set of source variants or name counts failed.
